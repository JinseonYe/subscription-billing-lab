# 구독 결제 서비스

## 문제 정의
외부 결제사 호출은 타임아웃이 나면 결제가 됐는지 알 수 없다.
이때 실패로 처리하면 돈은 나갔는데 구독은 끊기고, 다시 결제하면 이중 청구가 된다.
이 프로젝트는 결과를 모르는 결제를 상태 조회로 확정해서, 장애 상황에서도 청구를 정확히 유지하는 것이 목표다.

## 성공 지표
Mock PG의 타임아웃 비율을 0%, 30%, 50%로 높여도 아래를 유지한다.
1. 중복 청구 0건: 구독의 한 결제 주기에 실제로 청구된 결제는 최대 1건
2. 미확정 결제 0건: 확정 잡 실행 후 UNKNOWN으로 남은 결제 없음
3. 기록 불일치 0건: 우리 DB의 승인 목록과 결제사 승인 목록이 일치
